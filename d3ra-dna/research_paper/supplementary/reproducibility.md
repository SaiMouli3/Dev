# Supplementary S2: Reproducibility (revision 3)

Every number in the manuscript is read from a committed file in `d3ra-dna/results/`. The tables are generated by `research_paper/experiments/scripts/make_tables.py` and the figures by `make_dt_figures.py`; no table value is entered by hand. `research_paper/evidence/evidence_traceability.csv` maps each claim to its command and result file.

## Environment
- **Software:**
  - Python 3.13, Linux x86-64, 4 cores.
  - numpy 2.5.3, scipy 1.18.1, pandas 3.0.5, matplotlib 3.11.2, reedsolo 1.7.0, edlib 1.3.9, dt4dds 1.1.0.
  - Install with `pip install -r requirements.txt && pip install -e .`
- **Paper build:** pdfLaTeX + BibTeX with the official IEEEtran class v1.8b from CTAN.

## Seeds (bit-for-bit)
All randomness is seeded with `zlib.crc32` of a descriptive string, never with Python's randomised `hash()`:
- **synthesis:** `"scenario|rep|container"` XOR 20261102;
- **read order:** `"perm|..."`;
- **controller:** `"ctl|scenario|rep|perm|policy"`.

Results therefore do not depend on worker count or scheduling. A re-run check is in `evidence/verification_reports/rerun_check.txt`.

## Revision 2 reproducibility notes (real-read replay; superseded where they conflict with the above)

Every number in the manuscript is read from a file in `d3ra-dna/results/`. The files are produced by the scripts below. `evidence/evidence_traceability.csv` maps each claim to its script and result file.

### Environment used for the reported runs
- **Software:**
  - Python 3.13 on Linux x86-64, 4 CPU cores, 15 GB RAM.
  - numpy 2.5.3, scipy 1.18.1, pandas 3.0.5, matplotlib 3.11.2, plus reedsolo and edlib.
  - Minimum versions are listed in `requirements.txt`.
- **Paper build:**
  - pdfTeX 3.141592653-2.6-1.40.25 (TeX Live 2023), BibTeX with `IEEEtran.bst`.
  - IEEEtran class v1.8b, obtained from CTAN.
  - IEEE's own template download page returned an empty response to our automated download (see `audit/scientific_quality_report.md`). We therefore used the CTAN copy of the same official class, unchanged, together with `bare_conf.tex` as the structural reference. No unofficial template was used.
- **Code version:** the commit containing this directory, which builds on `main` at 3ba5f04.

### Seeds
| Item | Seed |
|---|---|
| Base seed of every experiment script | 0 |
| Empirical recovery-time matrices | seed + 7 |
| Surrogate T matrices | seed + 9 |
| Controller | seed + 11 |
| Paired bootstrap | `default_rng(0)`, 2,000 resamples |

- The per-run consensus-curve seed is `hash(run) % 2**32`. Python string hashing is randomised per process unless `PYTHONHASHSEED` is set, so set `PYTHONHASHSEED=0` for bit-identical φ̂ curves. The reported numbers were computed without fixing it. Re-runs agree closely but are not bit-identical; e.g. the ED flag rate of PCR_60c at R* was 73% in one run and 82% in a re-run (200 trials each), which exceeds binomial sampling error, and we have not fully traced the cause.

### Superseded result files
- `results/realdata_genscript_policies_roundrobin.csv` and `results/realdata_genscript_policies_part2.csv` were computed before the Genscript per-strand consensus cache was regenerated. The manuscript uses the `_v2` re-runs. On Genscript, mean costs moved by up to ~30% (e.g. single best 306k → 219k).
- The Twist `_v2` re-runs are identical to the originals (`realdata_policies.csv`, `realdata_failure_injection.csv`).
