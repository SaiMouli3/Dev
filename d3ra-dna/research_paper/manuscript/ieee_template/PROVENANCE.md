# Template provenance

- `IEEEtran/` is the official IEEEtran LaTeX class, v1.8b by Michael Shell, unmodified. It includes `bare_conf.tex` and the `IEEEtran.bst` bibliography style.
- It was downloaded from CTAN (https://ctan.org/pkg/ieeetran) on 2026-11-02.
- IEEE's own conference-template download (ieee.org, Manuscript Templates for Conference Proceedings) returned an empty HTTP response to our automated download. We therefore did not use the IEEE-hosted archive, and we did not substitute an unofficial template.
- Before submission, download the template from the target venue's page or the IEEE Template Selector and recompile.
- No venue is targeted yet. Any venue-specific requirements, such as page limits, copyright notices or PDF eXpress checks, still need to be applied.
